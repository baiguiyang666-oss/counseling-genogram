## 说明

- PNG 是二进制图片，无法在文件开头写文字注释，所以三个截图的用途统一登记在本文件里。
- 三张截图均为 2026-11-08 用 v1.2.0 当前构建重新生成（1440×900），与仓库内 `index.html` 的界面一致；旧版截图（文字按钮工具栏、13.5px 字号）已全部替换。
- 截图只用于文档展示，不参与程序运行；`index.html` 不引用这些图片（项目坚持零外链、零外部图片）。
- 截图内容来自示例数据，不含真实来访者信息。
